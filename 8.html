Tipos y tecnica de compresion de datos

Compresión sin pérdida (Lossless) No se pierde información. El archivo original se puede recuperar exactamente. Usada en texto, software, bases de datos, imágenes PNG. Ejemplos: ZIP, RAR, PNG, FLAC. Compresión con pérdida (Lossy) Elimina datos menos perceptibles para reducir más el tamaño. El archivo no se puede reconstruir al 100%. Usada en multimedia (imágenes, audio, video). Ejemplos: JPEG, MP3, MP4, AAC.

tecnica de compresion de datos

🔹Sin pérdida: Codificación Huffman: usa códigos más cortos para datos frecuentes. Algoritmo Lempel-Ziv (LZ77, LZ78, LZW): base de ZIP y GIF. Run-Length Encoding (RLE): comprime secuencias repetidas (ejemplo: imágenes simples). 🔹 Con pérdida: Transformada Discreta del Coseno (DCT): usada en JPEG para reducir información visual. Compresión perceptual: elimina sonidos o imágenes que el oído/ojos humanos no perciben fácilmente (MP3, AAC). Cuantización: reduce precisión de los datos para ahorrar espacio (audio y video).
