¿Qué es un dominio?

Un dominio es la dirección principal de un sitio web. Es único en Internet y permite a los usuarios acceder fácilmente a una página sin necesidad de recordar direcciones IP.

Ejemplo: www.ejemplo.com

¿Qué es un subdominio?

Un subdominio es una extensión de un dominio principal que permite organizar mejor el contenido de un sitio web.

Ejemplo: blog.ejemplo.com

Estructura de un dominio

Un dominio se compone de varias partes:

  • Subdominio: www
  • Nombre: ejemplo
  • Extensión: .com
